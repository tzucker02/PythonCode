1. Put the file in the same directory as the notebook on which you are working
2. In the notebook put this line near the top with your other imports: 
   `import omds`
3. Access the functions using the syntax 
   `omds.<functionname>(<function variables>)`
   
   for instance,
   
   `omds.find_ouliers(dataset)`
